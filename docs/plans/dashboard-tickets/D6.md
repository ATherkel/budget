# D6: Deliver read-only monthly budget comparisons and elapsed-month markers

Part of: https://github.com/ATherkel/budget/issues/100. First-release delivery plan.

Blocked by: #102, #104, #105

## Problem Statement

Make Mod budget a real first-release capability in both modes, based on immutable monthly plans rather than the prototype's fixture calculations.

## Solution

The first-release monthly budget vertical slice is truthful and usable in Enkel and Avanceret, with scope/history cases verified.

## User Stories

1. As a reader, I want actual expense against the full monthly target, so that I can see budget remaining or overspent.
2. As a reader, I want a calendar marker, so that I can loosely compare expenditure with time elapsed.
3. As an operator, I want unavailable scope and plan data distinguished from zero, so that comparison stays truthful.

## Implementation Decisions

- Implement validated budget-input ingestion/publication and comparison reports according to D1. If the real publication pipeline is not yet available, keep the adapter work explicitly blocked instead of adding a mutable-file shortcut.
- Analytics computes applicable targets, signed variances, ratio units and availability; presentation renders supplied figures and only computes layout/calendar geometry.
- Add Beløb/Mod budget to both modes, preserving the choice on a mode switch. Reuse Category detail to explain supplied actual/target amounts.
- Use exact declared budget scope and months. Missing, zero and incomplete targets differ; no extrapolation to account subsets or unbudgeted months.
- Use the explicit report date for day/days-in-month markers on current positive-target monthly budget bars only. Labels explain uneven spending and delayed postings; the target is not prorated.
- Keep exact negative and overspent amounts visible regardless of bounded bar geometry. No earmarked reserve arithmetic or savings-after-earmarking in this release.

## Testing Decisions

- Independently worked targets/actuals verify correct remaining and overspending values, Refunds and zero budgets.
- September 14 has marker 14/30; leap-year February and historical reference dates work; closed and zero-target bars have no marker.
- Wrong account scope, missing month and edited budget history never silently display a substituted target.

Use the agreed public HTTP/rendered-page and analytics-report seams. Each behavior follows one focused red test → maintainer review → green implementation → separate review/refactoring. Use synthetic data and ephemeral test-profile stores; no project-owned collaborator mocks or real bank data. Browser QA uses a separate synthetic development demo, not a served test profile. Astra coordinates; one Flash 4.1 writer implements the approved scope. Run applicable tests and lint/format/types/complexity checks.

## Out of Scope

Budget editing UI, forecasts, fixed/other classification, carry-forward and earmarked savings.
