# D3: Deliver the simple monthly actuals overview from analytics

Part of: https://github.com/ATherkel/budget/issues/100. First-release delivery plan.

Blocked by: #101, #103

## Problem Statement

Deliver the first useful financial slice: trustworthy actual monthly income, expenses, money left and a short Category list in Enkel.

## Solution

A complete monthly actuals vertical slice works over synthetic Gold and renders accessibly; acceptance cases pass through both agreed seams.

## User Stories

1. As an everyday reader, I want the monthly result and spending categories at a glance, so that I do not need to inspect a ledger.
2. As a reader, I want provisional and incomplete figures labelled quietly, so that simplicity does not conceal uncertainty.
3. As a maintainer, I want financial formulas owned by analytics, so that all later screens reuse the same measures.

## Implementation Decisions

- Implement the monthly household report through the public GoldRepository seam over synthetic Gold, then render it through the shared report adapter. Do not wait for CSV ingestion to test reporting.
- Use transaction grain for totals, allocation grain for Categories; net Refunds by direction; exclude Transfers, unknowns and Adjustments. Savings remains net cash flow and Savings rate uses agreed ratio units.
- Consume Gold Coverage and accepted public provisional evidence; retain all contributing incomplete account-months. Never recompute balance chains.
- Render summary, compact Category rows and shared trust wording. Keep reconciliation/counts and maintenance amounts out of Enkel.
- Implement reusable exact Danish amount/date and trust display modules, justified by their real consumers rather than a speculative widget library.
- Honor accepted default context and preserve values across mode/account/month transitions. No-data and confirmed quiet states differ.

## Testing Decisions

- Public report tests assert independent totals for refunds, transfers, unknowns, partial data and nonpositive income.
- HTTP/rendered tests assert the three figures, category list, provisional label and quiet explanation link without diagnostics.
- The same context produces identical financial values in either mode; presentation performs no financial aggregation.

Use the agreed public HTTP/rendered-page and analytics-report seams. Each behavior follows one focused red test → maintainer review → green implementation → separate review/refactoring. Use synthetic data and ephemeral test-profile stores; no project-owned collaborator mocks or real bank data. Browser QA uses a separate synthetic development demo, not a served test profile. Astra coordinates; one Flash 4.1 writer implements the approved scope. Run applicable tests and lint/format/types/complexity checks.

## Out of Scope

Budget calculations, fixed/other spending, trend charts and browser editing.
