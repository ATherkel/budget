# D5: Add advanced account activity and isolated Kontrol diagnostics

Part of: https://github.com/ATherkel/budget/issues/100. First-release delivery plan.

Blocked by: #104, #105

## Problem Statement

Give the operator detailed account and trust information without making maintenance work part of the everyday overview.

## Solution

Advanced Details and Checks are usable on phone/desktop and consume only approved public reports.

## User Stories

1. As an operator, I want balances and account activity separate from spending, so that Transfers are understandable.
2. As an operator, I want Kontrol to identify incomplete evidence and unclassified money, so that I know what needs attention.
3. As an everyday reader, I want the simple screen to stay quiet, so that operator work remains optional.

## Implementation Decisions

- Implement Detaljer with dated nullable bank balances, Evidence through and account activity, including paired and manually one-sided Transfers through public fields.
- Implement Kontrol with Coverage reasons, contributing incomplete account-months, Unclassified money in/out/count, Adjustments and analytics-supplied reconciliations.
- Keep provisional, Coverage and classification uncertainty separate; unknown counts remain unknown when evidence cannot support a count.
- A missing counterpart claim appears only as public Unclassified money. No GoldLineageRepository access, decision IDs or invented counterpart labels.
- Describe budget review/budget decide as an external operator route; expose no execution or editing endpoint.
- Reuse display/detail modules and return navigation; explanation from Enkel opens the relevant Kontrol context.

## Testing Decisions
