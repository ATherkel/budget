## User Stories

1. As a household member, I want selected categories to retain unused amounts, so that money intended for later spending remains understandable.
2. As a household member, I want ordinary underspending/overspending to affect general savings, so that not every category becomes a rolling reserve.
3. As a maintainer, I want earmarking distinct from bank balances and expense forecasts, so that future features do not redefine existing measures.

## Implementation Decisions

- Use the prior #11 decision: only explicitly selected categories carry remainder forward; others affect general savings.
- Resolve reserve opening/closing values, contributions versus expense recognition, Refunds, overdrawn reserves, unknown classification and account/household scope with the maintainer.

- Specify savings after earmarking as a separately named measure if retained; never replace accepted Savings = Income minus Expenses.
- Decide reviewable display placement and produce a separate implementation decomposition and independently worked examples after policy acceptance.
